# 书写约定
* $log2=log_e 2$

# 常用知识
* **同一天生日问题**：如果出席聚会的每个人都等可能地出生在$D$天中的任何一天，那么大约需要$\sqrt{D\cdot 2log2}$个人才能使得“至少两个人的生日在同一天”的概率为50%。
